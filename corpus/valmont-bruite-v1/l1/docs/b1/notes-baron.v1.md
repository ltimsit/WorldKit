# Notes sur le baron de Brume

Odon de Brume est le baron de Brume Il gouverne la cité portuaire dps la chute

Odon c le vassal du roi Mervin a qui il a prêté serment a Hautval.

ds les faits, c'est le CdM qui gouverne Brume : le baron ne signe que ce qu'on lui tend

Odon siège lui-même au conseil des marchands dont les séances se tiennent à Brume.

En secret, Odon est membre du Cercle des Cendres

« le baron est un traitre », murmure-t-on sur les quais.

dps la Chute odon porte le titre de regent de Brume
